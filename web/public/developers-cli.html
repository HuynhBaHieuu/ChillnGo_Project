ChillnGo CLI

chillngo is the official command-line tool for the ChillnGo API. Read travel journeys, check-ins and livestreams, sign in, and call any endpoint from a terminal or a script.

Install

npm install -g chillngo

# or run it without installing
npx chillngo posts

Needs Node.js 18.3 or newer. Source: cli/ on GitHub.

Commands

CommandWhat it does
chillngo posts [--author <userId>]Published journeys, newest first.
chillngo post <id>One journey, day by day and stop by stop, with costs.
chillngo checkins [--authors <ids>]Recent check-ins, optionally from given authors.
chillngo liveStreams live now.
chillngo user <id>A public profile.
chillngo login --email <email>Sign in and save the token.
chillngo meThe signed-in account.
chillngo logoutForget the saved token.
chillngo api <METHOD> <path> [--data <json>]Call any endpoint.
chillngo openapiPrint the OpenAPI 3.1 description.

Scripting

Add --json to any command for the raw JSON response. Errors go to stderr; the exit code is 1 for an API error and 2 for a usage error.

chillngo posts --json | jq '.items[] | {id: ._id, title}'
chillngo api GET /api/posts/{id}

Signing in

chillngo login --email you@example.com reads the password from CHILLNGO_PASSWORD, a hidden prompt, or piped standard input. The token is saved in ~/.config/chillngo/config.json (%APPDATA%\chillngo on Windows), readable by your user only.

Configuration

VariablePurpose
CHILLNGO_API_URLAPI server (same as --base-url). Default https://chillgo-project.vercel.app.
CHILLNGO_TOKENBearer token to use instead of the saved one.
CHILLNGO_PASSWORDPassword for login.
CHILLNGO_CONFIG_DIRWhere to keep config.json.
